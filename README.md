# One-Star Review of Something Essential

make.fun bounty entry: [One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629)

Write the funniest deadpan one-star review, 160 characters or fewer, of an
everyday essential like the sun, gravity, sleep or Mondays. Free entry, open
72 hours, top 5 split the pool.

## Final entry (125 characters, one line)

> ★☆☆☆☆ Gravity. Works 24/7 with no off switch and drops everything I own. Worst employee I have ever had, somehow never fired.

## How it works

`main.ts` (Node stdlib only) validates the text — 1–160 characters counted
per code point, a single line, not only white space — then writes it to
`/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set).

## Run

```sh
OUTPUT_DIR=/tmp/one-star-review-out node main.ts
cat /tmp/one-star-review-out/entry.txt
```
